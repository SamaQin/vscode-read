# VSCode Read

在 VSCode 编辑器视窗中显示小说内容的轻量阅读插件。小说正文保存在扩展专用数据目录，阅读位置持久化保存，切换编辑器或重启 VSCode 后仍可恢复。

阅读内容显示在当前代码视窗的中间区域，滚动时自动跟随，并根据活动文件语言使用对应的注释符号。显示区正好覆盖视窗中间的两行代码，不会修改代码文件。

## 使用

1. 在命令面板运行 `小说阅读: 打开/导入小说`。
2. 选择输入文本、导入 `.txt` / `.epub`，或从历史记录恢复。
3. 使用状态栏的书本入口打开阅读菜单。

也可以点击左侧活动栏的书本图标打开阅读控制界面。在侧栏中可以翻页、切换章节、隐藏内容，并调整文字透明度（输入 `10%` - `100%` 的百分比，回车或离开输入框后生效）、文字颜色（颜色选择器或 `#RRGGBB` 十六进制输入，留空跟随编辑器主题）和末页循环设置。快捷键通过侧栏入口在 VSCode 原生快捷键编辑器中修改。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Alt+Q` | 下一段 |
| `Alt+Shift+W` | 上一段 |
| `Alt+Shift+Z` | 下一章 |
| `Alt+Shift+X` | 上一章 |
| `Ctrl+Alt+Q` | 隐藏/显示 |

默认情况下到达末段会循环到开头，可在设置中关闭 `novelReader.loopAtEnd`。

快速跳转中，直接输入数字表示章节号，输入 `p` 加数字表示段落号，例如 `351` 跳到第 351 章正文，`p351` 跳到第 351 段。

## 开发与打包

```bash
npm install
npm run compile
npm run package
```

生成的 `.vsix` 文件可以通过 VSCode 的“从 VSIX 安装...”安装。

## 说明

VSCode 的装饰器不能改变文档内容，因此阅读文本以当前视窗中间的一行为锚点，渲染成覆盖该行及其下一行共两行的显示区；这两行用编辑器背景色盖住其后的代码，但不会修改或保存代码文件，滚动后遮住的位置会随锚点移动。对于空文档，VSCode 仍会提供一个默认空行作为装饰锚点。
